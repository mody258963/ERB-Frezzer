# خصم الفاتورة — الإيراد مقابل الربح

## مثالك

| البند | القيمة |
|--------|--------|
| سعر التكلفة | 85 |
| سعر البيع | 120 |
| الكمية | 20 |
| **إجمالي المبيعات (قبل الخصم)** | 120 × 20 = **2400** |
| **إجمالي الربح قبل الخصم** | (120 − 85) × 20 = **700** |
| خصم الفاتورة | **200** |
| **ما يدفعه العميل** | 2400 − 200 = **2200** |
| **الربح بعد الخصم** | 700 − 200 = **500** |

## السلوك الصحيح (بعد التحديث)

| المؤشر | المعنى | في مثالك |
|--------|--------|----------|
| `weekly_revenue` | إيرادات المحل **قبل** خصم الفاتورة (`subtotal`) | 2400 |
| `weekly_discount` | مجموع الخصومات | 200 |
| `weekly_net_sales` | صافي التحصيل من العملاء (`total`) | 2200 |
| `weekly_gross_profit` | ربح البنود قبل الخصم | 700 |
| `weekly_profit` | **الربح بعد خصم الفاتورة** | 500 |

الخصم يُخصم من **الربح**، وليس من إيراد المبيعات الإجمالي.

## API

`GET /api/v1/dashboard/summary`

```json
{
  "weekly_revenue": 2400,
  "weekly_discount": 200,
  "weekly_net_sales": 2200,
  "weekly_gross_profit": 700,
  "weekly_profit": 500
}
```

## إنشاء الفاتورة (لم يتغير)

`POST /api/v1/invoices`

```json
{
  "discount": 200,
  "items": [{ "part_id": "...", "quantity": 20 }]
}
```

- `subtotal` = 2400  
- `discount` = 200  
- `total` = 2200 (المبلغ على العميل)

## تطبيق Flutter

اعرض في لوحة التحكم:

- **إيرادات الأسبوع** ← `weekly_revenue`  
- **خصومات** ← `weekly_discount`  
- **صافي المبيعات** ← `weekly_net_sales`  
- **ربح الأسبوع** ← `weekly_profit` (وليس `weekly_revenue − التكلفة` يدوياً)

بعد النشر على السيرفر: `php artisan cache:clear` (لوحة التحكم مخزنة مؤقتاً 5 دقائق).
